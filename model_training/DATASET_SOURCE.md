# Dataset source

The local dataset was prepared from the public
[JingmingWang/AI-generated-Image-Detection](https://huggingface.co/datasets/JingmingWang/AI-generated-Image-Detection)
dataset on Hugging Face.

- 50 real photographs from `Real Human Photo Dataset`
- 50 AI-generated images, selected equally from the Doubao and Kimi generator folders
- Split: 70 training, 16 validation, and 14 test images
- The source dataset describes the images as academic research data; review its license before commercial use.

The image files are intentionally ignored by Git. Keep this file with any locally
prepared dataset so its provenance remains clear.
